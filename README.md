# Jeu-d-checs-projet-universitaire-
Voici le résultat d'un projet universitaire réalisé en duo avec une autre étudiante de ma formation. Le projet consistait à faire un jeu d'échec en suivant les contraintes imposées dans le sujet  qui nous était donner, puis de détailler les parties du projet que nous avions réussis, échoués, ou sur lesquels nous avons rencontrés des difficultés.
Pour lancer le jeu, ouvrez votre terminal puis lancez la commande "java Main".
